# 🚀 DSA Tracker (A2Z Sheet Progress Tracker)

A clean and simple web app to track your Data Structures & Algorithms progress.
Inspired by the Striver A2Z sheet, this project helps you stay consistent and organized while solving problems.

---

## ✨ Features

* 📚 Topic-wise problem tracking (Arrays, Strings, etc.)
* ✅ Mark problems as Done / Undo
* 📊 Progress visualization (coming soon)
* 💾 Persistent state (LocalStorage / Backend planned)
* ⚡ Fast and responsive UI

## 🚀 Getting Started

### 1. Clone the repository

```
git clone https://github.com/your-username/dsa-tracker.git
cd dsa-tracker
```

---

### 2. Install dependencies

```
npm install
```

---

### 3. Run locally

```
npm run dev
```

Open: http://localhost:5173/
